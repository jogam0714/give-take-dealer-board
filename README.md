# 순위 예측: 기브 & 테이크 — 진행자용 게임판

5명이 10라운드 동안 카드를 주고받는 게임을 진행하는 정적 웹 게임판입니다.

## 사용 방법

1. 진행자 보기를 켜고 플레이어 이름·보유 가넷·비공개 예측을 입력합니다.
2. 예측을 봉인한 뒤 플레이어별 기본 카드 두 장과 추가 아이템을 제출합니다.
3. 전원 제출 후 득점을 계산하고, 공개 결과와 개인 득점을 안내합니다.
4. 5라운드의 중간 순위와 10라운드의 최종 판정을 순서대로 공개합니다.

아이템 구매·보유 카드·개인 득점·예측은 진행자 보기에서 관리합니다. 공개 보기로 전환하면 개인 정보를 화면에서 숨깁니다. 새로 열거나 경기 파일을 불러올 때는 공개 보기로 시작합니다.

## 현재 적용 규칙

- 기본 카드 20장(−10~−1, +1~+10), 자기 자신에게 한 장·다른 플레이어에게 한 장을 비공개로 제출합니다.
- 아이템 구매는 비공개이며 +11 또는 −11 중 한 장(3가넷), 0 한 장(1가넷)까지 구매할 수 있습니다.
- 5라운드가 끝나면 누적 점수의 순위만 공개합니다.
- 누적 점수 동점은 최근 라운드부터 역순으로 비교합니다. 10라운드 각각의 득점까지 같으면 재경기가 필요하다고 표시합니다.
- 독대는 참여자마다 1가넷을 지불하고 10분 타이머로 진행합니다.
- 최종 순위는 예측 성공자를 점수 순위대로 먼저 배치한 뒤 예측 실패자를 배치합니다.

## 경기 기록

경기 기록은 사용 중인 브라우저의 로컬 저장소에 저장됩니다. 이 저장소에는 앱 소스와 비어 있는 기본 화면만 포함됩니다.

기존 사이트나 다른 기기의 경기 기록을 옮길 때는 기존 보드에서 **경기 파일 저장**을 누른 뒤 새 보드에서 **불러오기**를 사용합니다. 경기 파일에는 비공개 예측·카드·개인 점수가 포함됩니다.

## 빌드와 배포

Node.js 18 이상에서 실행합니다.

```sh
npm install
npm run build
npm test
```

빌드하면 독립 실행 가능한 `docs/index.html`을 생성합니다. GitHub Pages는 `main` 브랜치의 `/docs` 폴더를 게시하도록 설정합니다. 수정 후 빌드 결과도 함께 커밋하면 게시 화면이 갱신됩니다.
